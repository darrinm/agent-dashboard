Under the hood

  • A native SwiftUI panel. The icon is a non-template image: colors were tested on this Mac's menu bar, and blinking is limited to unseen requests to stay within the CPU budget.
  • Activity lines plot output tokens per minute over 15 minutes from transcript and rollout token counts. Dotted baseline: a tool was running. Flat: nothing produced.
  • Claude inventory uses claude agents --json, transcripts and hooks. Test Codex's shared App Server before its file fallback.
  • Remote sessions use a hub; unavailable sources stay visibly unavailable.
  • ⌥ Space opens the panel from anywhere. Arrow keys move between sessions; Return expands one.

Mockup, not live monitoring. Names, messages, identifiers, projects, and machines are sample data. Activity lines retain measured, anonymous token counts from a development spike. Individual wait ages are illustrative to demonstrate newest-first ordering within the reported 13–27 day range. Session actions do not execute.
